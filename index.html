🧱 Live grid walls

Split any screen into grids and load a live web page, BI dashboard, PDF or Office document into each one. Lock grids to protect their content.

📌 Split view

Pin the page that matters into a large pane and keep the rest of the wall at a glance beside it.

📑 Bulk loading

Fill a whole row from a CSV link list or a folder of documents in one action — built for control rooms and morning reviews.

🗂 Multiple walls

Several dashboards per workspace, one click apart. Layouts, zoom levels and content survive restarts.

🏢 IT friendly

Per-user install, silent deployment via Intune/GPO, system proxy support, folder-access policy and a one-click diagnostics bundle.

🔄 Manual updates

The app tells you when a new version exists — you decide when to install it. Nothing updates itself behind your back.
